# Acorn Niri
This repository holds my personal Niri config as I presently use it. This config is not designed to be entirely original, nor to be distributed or tauted as a full project. It is simply the configuration that I use on my work laptop day-to-day.

The main principle I follow with this setup is one of "don't complicate things". For example - sure I can and have set up custom bars or quickshell setups. But the way I would set one up would be effectively a worse version of something like Noctalia, so I skip the step and use it.

## Dependencies
- [Niri](https://github.com/niri-wm/niri)
- [Noctalia](https://noctalia.dev)
- [Ghostty](https://ghostty.org/)
- [Firefox](https://github.com/mozilla-firefox/firefox)
- [Equicord](https://github.com/Equicord/Equicord)
- [Nautilus](https://gitlab.gnome.org/GNOME/nautilus)
- [Yazi](https://yazi-rs.github.io/)
