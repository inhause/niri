# acorn-niri

Acorn' Niri dotfiles

This is a relatively minor setup, more or less my default go-to for my work laptop with my preferred settings for productivity. Still very much a *work-in-progress.*

This config is not made to work on all devices, it is the setup I use for *my* laptop.

Acorn currently runs using [Noctalia](https://noctalia.dev/) as the shell/bar of choice. If you want to ensure that the config works, it is the most important of the dependencies at the moment.

## Dependencies
- Noctalia
- Ghostty
- Firefox
- Nautilus
- Yazi
- Vesktop
